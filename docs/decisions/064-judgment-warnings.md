## Ruling

A warning on a kit page is resolved on the page. The gallery and the sample report carry no standing
warnings, so a new warning on either is a new finding. A check changes only where it misreads the
spec, and the spec changes only by a ruling. Warnings still never fail a run.

## Rulings

| Item | Ruling | Changed |
| --- | --- | --- |
| Summary numbers | Every number in the summary is stated again in the body, in the prose beside the figure that sources it | Sample: the demand prose states 7.4% against Q2's 44,870; the service prose states the backlog's 39% fall from 1,940; the sentiment prose states 0.6 pp below the 88% target |
| Reading time | The count is the words in `<main>`. Scripts, chart data tables and screen-reader-only text do not count; a word is a run of characters between spaces that holds a letter or digit. The spec states this beside the formula | `SPEC.md` section 7. Sample: 1,433 words, 7 min |
| Bold colon | A label before a colon is bold. Where bolding would set one item apart from plain siblings, or bold most of a sentence, the sentence is recast without the leading colon. The rule covers table cells and definition values as well as sentences, list items and captions | Sample: one methodology item recast. Gallery: the spacing scale's two labels bolded; six sentences recast (a tile, an anatomy cell, two component descriptions, the collapsible demo, a checklist item) |

## Checks

Unchanged. The reading-time check stays a warning: the figure is an estimate for the reader, and a
wrong one does not make a report unpublishable.

## Alternative not taken

Exempting the gallery's own prose from the writing rules. The gallery states the bold-colon rule in its
checklist, so its prose follows it; its catalogue exemptions cover layout and report anatomy only.
