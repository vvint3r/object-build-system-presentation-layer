00 Ten things that are not up for reinterpretation
Each of these was decided once, for a reason, and each has already been broken at least once by someone who assumed otherwise. Breaking one is not a style choice; it makes the new panel read as a different system.
01Charts are rendered, diagrams are drawn. A chart is an ECharts 5.5.1 option object on the SVG renderer. A diagram is SVG written by hand, coordinate by coordinate. Never hand-draw a bar chart; never ask a graph library for a diagram. 02Three greys, and no fourth. Page #171717, panel #191919, node #151515. Node fill must be opaque — the depth rect sits behind it. 03Content text is #ffffff. Grey belongs to axis ticks, legends, captions and source lines — never to a node's own content. Emphasis is weight, never opacity. 04Four hues carry meaning. Teal is running or ok, yellow is waiting, coral is stalled or failed, blue is informational; 22% white is nothing running. Colour encodes exactly one variable, and the panel says which. 05Panel widths are a closed set: 349, 600, 730, 900, 1200. Canvas is the panel less 48px — 24px of padding each side. Do not invent an intermediate width to make something fit.
06Nunito for words, Fira Code for numbers. Every figure, identifier, tick, unit and code fragment is Fira Code. Nunito 300 fails below 13px on this ground — the stems fringe — so small text is weight 500 or heavier. 078px standoff, both ends, every arrow. An arrowhead never touches a box and never begins or ends inside a label. This is the single most common defect in the set. 08Measure painted extent, not bounding boxes. A knockout halo adds 2px on every side; a depth rect adds 4px below and to the right. Clearances computed on the box are wrong by exactly those amounts. 09Every panel carries three things: a one-line how-to-read above the drawing, a legend naming every colour and mark that appears in it, and a caption stating what the drawing argues — not what it contains. 10Resize a box and everything near it is stale. Connectors, cardinality markers and labels all hold coordinates measured against the old edges. None of them move on their own. Re-measure, or redraw.

Letter-spacing — the one thing ECharts cannot do
ECharts has no letterSpacing option in any textStyle, at any version. The 1.2px token can only be applied from outside, with a CSS rule on the rendered SVG:
.chart svg text { letter-spacing: .5px }
Which is the whole reason the renderer is 'svg' and not canvas. Switch to canvas and every chart on the page silently loses its tracking, and no option object anywhere will explain why.

04 Charts · three palettes, two ramps, and where each one stops working
The palette is a page-level prop, not a per-chart choice — all seventeen switch together. Each palette has a hard series ceiling, and past it two slots merge under one of the three common colour deficiencies. The ceiling is the number that matters when you add a series.
A · Signature RECOMMENDED
#25d09d #ff7d8a #6ea8ff
#ffca00 #b191ff #3fb6c9
Coral sits in slot 2 so a two-series chart gets maximum hue separation rather than teal beside blue. Cyan is #3fb6c9, not #46d4e0 — the original sat 8° from teal at nearly the same lightness and collapsed under deuteranopia.
Ceiling 4 for protan and deutan, 6 for tritan. All ≥4.5:1 on #171717.
B · Voltage
#00da8e #f8007c #ffdf00
#00b4ff #a56bff #4bf07a
Reads loud and works as strokes. Slot 6 is #4bf07a rather than pure #00ff1a — full-chroma green halates on OLED and its 1px strokes bloom into fuzz.
Ceiling 4. #00da8e and #4bf07a merge for deutans — never adjacent. Strokes and marks, not large fills.
C · Okabe-Ito, dark-lifted
#17b58a #56b4e9 #eda51a
#dd8ab6 #8f9bff #ece463
The Okabe-Ito set lifted in lightness for a #171717 ground — #0072B2 was too dark to read and became #8f9bff. Off-token: teal is no longer #25d09d.
Ceiling 6 under all three deficiencies. Use at six or more series, or when the chart leaves the team.
Sequential — magnitude · heatmap, treemap, single-hue bar, funnel
#12241f #173a30 #195244 #1a6c57 #1a886c #1ea683 #25d09d #6ee2c0 #b4f0dc
Nine OKLCH-even steps through the accent hue. Step 1 is only 4% lighter than the panel, so the low end reads as present-but-empty rather than as a hole. Feed to visualMap.inRange.color. Steps are indexed 1–9 left to right; §05 refers to them by number.
Diverging — signed change · variance, delta, sentiment
#ff9aa4 #e0707d #a8515c #6b3a41 #2e2e2e #1f5348 #1a8a6c #25d09d #8ae8c9
Coral to teal through a neutral #2e2e2e midpoint, not through white. On a dark ground a light midpoint becomes the loudest thing in the chart, which inverts the meaning of no change.

09 Connectors and labels — the system that took the longest to get right
Two systems competing for the same space: every bar carries a label, and every handoff needs the space directly above or below a bar to leave from. Changing one breaks the other, and that coupling is the whole problem. What follows is the current, measured state of 4c — it supersedes scraps/4c-brief.md, which describes the previous spline model.
The curve — runnable
const NORM = { top:[0,-1], bot:[0,1], left:[-1,0], right:[1,0] }; const STAND = 8, K = 0.5, HMIN = 10, HMAX = 92; const sub = (a,b) => [a[0]-b[0], a[1]-b[1]]; const add = (a,b) => [a[0]+b[0], a[1]+b[1]]; const mul = (a,s) => [a[0]*s, a[1]*s]; const len = a => Math.hypot(a[0], a[1]); const unit = a => { const l = len(a) || 1; return [a[0]/l, a[1]/l]; }; const r = n => Math.round(n * 10) / 10; // from / to: { anchor:[x,y] on the bar edge, edge:'top'|'bot'|'left'|'right' } function connector(from, to, waypoints = []) { const n0 = NORM[from.edge], n1 = NORM[to.edge]; const A = add(from.anchor, mul(n0, STAND)); // 8px clear const B = add(to.anchor, mul(n1, STAND)); // arrowhead tip const pts = [A, ...waypoints, B]; // end tangents are the edge normals; interior tangents are chordal const tan = pts.map((p, i) => i === 0 ? n0 : i === pts.length - 1 ? mul(n1, -1) : unit(sub(pts[i+1], pts[i-1]))); let d = `M${r(A[0])},${r(A[1])}`; for (let i = 0; i < pts.length - 1; i++) { const a = pts[i], b = pts[i+1], v = sub(b, a), L = len(v); // handle length: half the travel ALONG THAT NORMAL, not along the chord const h = t => Math.min( Math.max(K * Math.abs(v[0]*t[0] + v[1]*t[1]), HMIN), HMAX, 0.62 * L); const c1 = add(a, mul(tan[i], h(tan[i]))); const c2 = sub(b, mul(tan[i+1], h(tan[i+1]))); d += ` C${r(c1[0])},${r(c1[1])} ${r(c2[0])},${r(c2[1])} ${r(b[0])},${r(b[1])}`; } return d; } // Try direct FIRST. Why the handle rule is written that way
Scale the handle by the chord and a short sideways step gets a 40px handle on an 8px horizontal travel: the curve balloons out past its target and comes back. Scale it by the travel along its own normal and the same step gets the 10px floor — a tight quarter-turn — while a 200px climb gets the full 92 and bows across its whole length.
The 0.62 × L cap is what stops two handles crossing on a short segment, which is the other way to produce a loop.
The test that catches the defect nothing else catches
A kink at the tail or a small loop under the arrowhead passes every clearance check — it is inside the standoff, touching nothing. It shows up only as a tangent reversal: the derivative pointing back against the segment's own chord.
function reverses([p0, c1, c2, p1]) { const ch = unit(sub(p1, p0)); for (let k = 0; k <= 24; k++) { const t = k/24, u = 1-t; const dv = [ 3*u*u*(c1[0]-p0[0]) + 6*u*t*(c2[0]-c1[0]) + 3*t*t*(p1[0]-c2[0]), 3*u*u*(c1[1]-p0[1]) + 6*u*t*(c2[1]-c1[1]) + 3*t*t*(p1[1]-c2[1]) ]; if (dv[0]*ch[0] + dv[1]*ch[1] < 0) return true; } return false; }

10 The twenty drawing rules, then the reject list
Written from the faults actually found in the existing panels, not from a style guide. The numbers are in the drawing's own units at the type sizes the kit states — shrink the type and every number moves. Walk the list before calling a panel finished.
CLEARANCE
01Every connector ends 8px clear of the node it points at and starts 8px clear of the node it leaves. An arrowhead never touches a box. 02No connector crosses a node or a label. Where the direct line would, route through the nearest clear corridor and enter the target from its side. Crossing a phase boundary is fine — that is what a transition does. 03A connector never approaches a node on the side its label occupies. On a bar row that side is the top, so a handoff leaves and enters at the bottom or the side. Where a terminus lands beside a text run it stands 8px off that run's painted box, halo included; an arrow that begins or ends inside a label is the failure this rule exists to catch. 04A node label clears its box by 8px, measured to the descender, not the baseline — and to the outside of the knockout halo where it has one, which is 2px past the descender. Measured, not assumed: a 10.5px label paints 3.5px below its baseline, so a haloed one paints 5.5px below it and wants a 14px gutter to hold 8px of air. 05A label that rides a connector sets its baseline 8px off the line — 4.4px of air under the descender at 10px, the same in every panel. Cardinality markers are the exception: they sit against the line they annotate. 06Measure all of the above against painted extent, not the bounding box: a knockout halo adds 2px on every side, a depth shadow adds 4px below and to the right.
PADDING
0716px from a node border to its first mark; 14px from its last text to the far border. A field-list node — a title, a rule, then rows — is a different species: 14px on the sides, its rule 32px below the top border, rows on a 24px pitch, and 7px of air under the last row's descender. There the pitch sets the bottom inset, not the padding number. 08On a two-line node both lines share one left edge. A leading dot sits outside that edge, never on it. 0910px minimum from any text to the panel frame. A phase divider is a hairline, not a container: text sits 6px off it, and symmetrically — the phase name 6px right of its divider, the duration 6px left of the next. A node's own border is rule 07's business, not this one.
TYPE
1012px minimum for a node's title line at 900 and above; 10px is the floor in the 600-wide compact panels. 9px is the metadata tier and nothing else — units, axis labels, dwell times, and key or state markers set inside a node. 11Hierarchy is size and weight. The first line is 600, the second is 400 — and both are white. 12Grey #7d7d7d belongs to axis ticks, legends and captions. Never to a node's own content.
ALIGNMENT
13One left edge per panel: the drawing, its how-to-read line, its legend and its caption all start at the same x. 14Nodes in a row share a top edge; labels in a row share a baseline. 15Sibling nodes that mean the same kind of thing share a width.
COLOUR
16Teal is work running, yellow is waiting, red is stalled, grey dashed is nothing running. No other hue carries meaning. 17Colour encodes one variable. Size may encode one more, and the panel has to say which.
EVERY PANEL CARRIES
18A one-line how-to-read above the drawing. 19A legend at the foot naming every colour and mark that appears in it. 20A caption stating what the drawing argues, not what it contains.
After resizing any box, re-measure every mark that was placed against its old edges — connectors, cardinality markers and labels all carry those coordinates and none of them move on their own.
REDRAW, DO NOT NUDGE, IF
an arrowhead overlaps text a connector crosses a box labels in one row sit at different baselines a node's own content is grey the legend omits a mark that appears equal boxes on a grid carry unequal quantities
Rules 01 to 05 account for most faults found so far, and an arrowhead resting on a label is the single most common — because the standoff was set against the box and the label was never measured. The reject list is separate because those six are not finishing errors: each one means the drawing is encoding something it has not earned, and adjusting the geometry hides it rather than fixing it.
