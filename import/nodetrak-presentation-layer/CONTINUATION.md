## The locked visual language (option "2a" — do not drift)
- Fonts: Nunito (300–900) reading/display; JetBrains Mono (400/600/700) for ALL labels, metadata, timestamps, tables, badges, code. Mono labels: ~9–10px, 700, uppercase, letter-spacing .08–.1em.
- Focus: global 2px black ring, 3px offset; interactives are real elements. Type floor: labels ≥9.5px, ticks 9px, nothing <9. Responsive: structural media blocks — rails→strip ≤1150, min-widths release ≤800, 1fr grids stack ≤640. Semantic chips always 1px black border. Radii add 6 code / 2–3 bar caps; 5 and 10 retired.
- **Text is #000 or #fff only. NO grey text ever.** Hierarchy = weight 300→900 (300 de-emph, 400 body, 600 gentle, 700 labels, 800 component titles, 900 display). De-emphasis may also use opacity on structure (not tinted text colors).
- **Accent #1de9b6 (teal) is never text.** Only: bars (36–52px × 4-5px pills), link underlines (2px), borders, chip fills, the reserved offset shadow, column washes (rgba .12/.25/.3), list bullets.
- Greys are structural only: #fafafa canvas, #fff surface, #f1f1f1 track/fills, #e4e4e4 hairline, #d9d9d9 dotted dividers.
- Semantics (black text on bright fills + always a mono label): ok #00e676, warn #ffd600, crit #ff5252, info #40c4ff, note #b388ff. Neutral chip = white + 1px black border.
- Depth: L0 hairline · L1 hover lift (−1,−1 + `3px 3px 0 rgba(0,0,0,.18)` + black border) · **L1e emphasis** (1.5px black border + `6px 6px 0 rgba(0,0,0,.08)`, static) · **L2 reserved** (1.5px black + `5px 5px 0 #1de9b6`) — **at most ONE untagged L2 per view** (docs specimens carry dashed SPEC tags) · L3 overlay (`10px 10px 0 rgba(0,0,0,.12)`).
- **Borders never nest**: tiles/nodes inside a bordered container are #f1f1f1 fills, not outlines (exceptions: emphasized nodes, decision diamonds, DFD entities).
- Shape: pills (999) for ALL interactives; cards 14, tables 12, inputs 8, chips 4. Buttons: primary black pill (hover: teal offset + lift), secondary outline, subtle track-fill; active tab = white pill + 1px black border + `2px 2px 0 #1de9b6`.
- Layout: 1060px content grid, 70ch reading column, 96px section rhythm, 4px base scale. Body 15/1.85 (generous). Sections: teal bar → `§NN` mono + 900 title → intro ≤70ch.
- Page chrome: sticky white header (brand 900 16px + outline chip + mono nav pills, hover teal wash 30%), masthead (52×5 teal bar, 900 40–52px title), mono footer. Cross-link all pages in headers.
- Links: black text, teal 2px underline, hover teal wash. `::selection` teal .35.

## DC authoring notes (environment specifics)
- Inline styles ONLY (no classes); helmet holds fonts + body/a/::selection resets. `style-hover` for hover states.
- **Never `<sc-for>`/`<sc-if>` inside `<table>`/`<thead>`/`<tbody>`** — the parser hoists it out and every hole inside renders empty (cost: eight blocks shipped blank for seven rounds). Tabular layouts are grid rows.
- Interactivity via logic class `Component extends DCLogic`, `renderVals()` returns holes; `sc-if`/`sc-for` with hint attrs. Existing live pieces: tabs (Foundations, DFD), checklist, quiz, decision-tree walk, concept-map inspect, taxonomy toggle.
- Diagram connectors: flex line div (`height:2px;background:#000`) + CSS-triangle arrowhead; dotted = `border-top:2px dotted`; labels = tiny mono chips at `top:-14px`; loops/merges = absolute ⊔ elbows (border-left/right/bottom + bottom radii) in a spanning grid row; diamonds = rotated squares whose cell width ≈ diagonal (tips touch lines).
- User cares intensely about: alignment precision, generous spacing in diagrams/grids (gaps ≥12–14 between tiles), no visual noise, no grey text. They review closely and give layout-level feedback.
