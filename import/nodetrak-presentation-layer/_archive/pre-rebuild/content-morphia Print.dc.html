The printed form

Every page prints from the same source it renders from. There is no second design for paper: each token has one printed value, each control has one resolved state, and a diagram too large for a sheet decomposes by the level model it already carries.
ss: 01

What paper removes

Paper takes three things away and gives one back. It removes interaction, blurred depth, and — on any monochrome device — colour. It gives a fixed page box, which is why nothing printed scrolls, floats or overlays, and why a sheet is the unit that material has to fit.

What the page box fixes

Screen geometry is relative to a viewport; printed geometry is relative to a sheet. Four values are settled once and never restated per document.

The print contract
Every accent mark in this system is redundant with a shape, a position or a label, and every semantic fill carries its mono word. Printed in greyscale, a document therefore loses emphasis and no information. A mark that fails that test is not a colour problem to solve at the printer — it is redrawn.
ss: 02

One printed value per token

The substitution is mechanical and complete: every token in the system resolves to exactly one printed value, and no printed value is chosen at print time. Percentages are of black; rules and type are in points, because a printed measure that is stated in pixels is not a measure.

ss: 03

Diagrams on paper, by tier

A diagram is scaled to the page box only while every label holds the print floor of 8pt. Past that it is not shrunk and it is not cut at the margin: it decomposes into sheets by the same level model it carries on screen. The three capacity tiers each have one printed form, shown here against the ecosystem canvas — forty-four nodes over three levels.

ss: 04

Every control, resolved

A control on paper is a dead control, so no control prints. Each one either resolves — the material it governs prints in the state it was in, with that state stated in words — or it has no printed form at all and is removed. Nothing prints inert.
