Provenance at aggregation density

A node in this index is not written, it is aggregated: hundreds of sources are read, reconciled and re-read on a cadence. Provenance grammar built for a single cited author cannot describe that. These four components replace it — the aggregation header, the agreement and spread pair, the confidence qualifier, and citation that counts rather than points.
Components 4 components · 6 rules · specimens run on one node at 214 sources
ss: 01

The aggregation header

Every context node opens with the same four facts, in the same order, in the same place: how many sources it rests on, when it was last re-aggregated, how often that happens, and when it is next due. A reader who returns after a month needs those four before the first sentence, not in a footer.
Staleness follows from the last two, so it is never stated independently. The bar measures elapsed time against the cadence, and the tint names the state it has reached.

ss: 02

Agreement and spread

A finding drawn from hundreds of sources has two properties a single-source finding does not: how many of them agree, and how far apart the ones that quantify it land. Both are stated, and neither substitutes for the other — strong agreement on a wide spread is a different claim from weak agreement on a tight one.
Sources with no position are counted and shown. Dropping them would turn a minority of the quantifying sources into a majority of the whole.

ss: 03

The confidence qualifier

Confidence is derived, not asserted. Three levels, each defined by thresholds on the numbers already in the header, and each licensing a different use downstream. A qualifier attaches to a claim, never to a page — one node routinely carries a high-confidence method and a provisional cost figure.

All three thresholds must hold for a level; failing any one drops the claim to the level below. A claim cannot be promoted by editorial judgement, and the tint is redundant with the word, which is always present.
ss: 04

Citation at density

A footnote marker points at one source. A claim resting on ninety-six cannot be footnoted, and a list of ninety-six references is not a citation — it is an appendix nobody reads. The marker therefore states the count, and opens a panel that characterises the set rather than enumerating it.

Attribution names a role, not a person. Nobody wrote the claim; a pod accepted it, and the accountable unit is the one a reader can go back to in six months. Named individuals appear only where a source is a person, inside the panel.
The panel is also the resource centre. A separate library page listing everything the index has read would be a second, worse index — sources are reachable from the claim that rests on them and nowhere else.
