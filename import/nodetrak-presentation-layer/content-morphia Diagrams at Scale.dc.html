The diagram library proves the grammar at seven nodes. This page governs what happens at forty. Capacity ceilings, levelled abstraction, legends, node registries, and edge routing — then one ecosystem map that runs the whole set live.
Every tier has a hard node count, and each ceiling brings an obligation. A diagram that outgrows its tier does not get smaller type — it moves up a tier or splits into levels.

Label discipline

Node names truncate at 24 characters with an ellipsis. The untruncated name lives in the registry table, never in a tooltip alone. Node boxes are one fixed width per canvas — never sized to their content, which is what makes columns read as columns.

Scale is handled by abstraction, not by fitting more boxes on screen. One map, three levels, each a complete diagram in its own right. Descending is always initiated from a node — you click the thing you want to open, and the crumb records where you came from.

The level ladder

L0Context
The system as one box, plus who touches it. Names say what things do, never how they are built. 5–12 nodes.
L1Containers
Deployable pieces and the data moving between them. This is where lineage lives. 15–40 nodes.
L2Components
Inside one container. Built selectively — only where readers actually need it. 8–25 nodes.

Crumb pattern

L0 · Context › L1 · Containers › L2 · dbt core
The current level is the only bordered crumb. Earlier crumbs stay clickable and return the canvas to that level with focus and filters cleared.
Three node types is the threshold: at three or more, a legend is mandatory and sits pinned to the top-right of the panel, never floating over the drawing. The registry table is the text alternative promoted to a first-class component — at T3 it is required, and it carries what the boxes cannot.

Registry carries

Stable id · full untruncated name · type · layer · owning team · upstream and downstream counts. Sorting and search operate on the registry, and the canvas follows it — the table is the source of truth, the drawing is the view.
Ids are the off-page connector vocabulary too. An edge that leaves the frame terminates in a chip bearing the target id, and that id resolves in the registry below.
Edges are what break first. Past roughly twenty, arbitrary routing turns a diagram into a thicket, so routing is constrained rather than optimised: orthogonal only, corners rounded to 10px, one turn band between columns.

Routing

Leave the source at right-centre, turn once in the gap between columns, enter the target at left-centre. Return edges drop below the last row and travel back in a dedicated band.

Weight encodes volume

Where a flow carries magnitude — rows, events, spend — stroke weight steps 1.5 / 2.5 / 4. Three steps only, and the legend names them. This is how lineage reads as lineage without a second colour.
