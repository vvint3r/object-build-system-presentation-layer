What needs no equivalent

A mark whose value is already written beside it has its equivalent: the writing. Magnitude bars in a labelled row, progress tracks that state their count, legend swatches, section bars and status chips take nothing further. Adding a table under a six-pixel bar restates a number that was never hidden.
The rule this page exists for
A diagram, a chart or an interactive visual is never the only route to a fact. If a number exists nowhere but inside a mark, or appears only when a mark is selected, the mark is not the problem — the equivalent is missing.
One sentence, assembled in a fixed order: what kind of thing it is, how much of it there is, how the parts relate, and the one thing a reader would have noticed by looking. It describes what the visual shows and never what it looks like — no colours, no positions, no shapes.
