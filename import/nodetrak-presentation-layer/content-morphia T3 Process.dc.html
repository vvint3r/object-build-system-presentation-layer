Six steps from hypothesis to decision memo. Every failed test we have audited skipped a step — usually sizing or the guardrail check.
Process 6 steps · 3 roles ~25 min · intermediate · updated Jul 2026

Preconditions

✓ Randomized assignment available at the right unit (user, session, account) Tool
✓ Primary metric and guardrails defined — see HEART for choosing them Knowledge
✓ Event instrumentation QA'd in the last 90 days Task
The six stepsroles · PM / Data / Eng
1 Frame the hypothesisPM One sentence, falsifiable, with a named mechanism: "changing X will move Y because Z." IN: opportunity brief → OUT: hypothesis doc
2 Size the testData Fix the minimum detectable effect first, then compute sample size and duration. Duration is an output, never an input. IN: baseline rate, MDE, α → OUT: n per arm, run length
3 Build and QAEng Variant behind a flag; assignment and exposure events verified end-to-end on staging before any traffic. IN: hypothesis doc → OUT: flagged variant, event QA log
4 Launch on a rampEngData 5% → 25% → 50% with a sample-ratio check at each gate. Ramp time does not count toward the run length. IN: QA'd variant → OUT: ramp log, SRM checks
5 Monitor guardrails onlyData Watch crashes, latency, and revenue guardrails daily. The primary metric stays sealed until the planned end date. IN: ramp log → OUT: daily guardrail record
6 Decide and write the memoPMDataDecision gate Ship, hold, or iterate — one page, pre-registered criteria, guardrail table attached. "Interesting, run it longer" is not one of the three options. IN: sealed results → OUT: decision memo

Exceptions — stop conditions

Critical
Sample ratio mismatch
Arms deviate from the planned split (χ² p < .001). Assignment is broken; results are unreadable. Stop, fix, restart.
Warning
Peeking at the primary
Reading the primary metric early inflates false positives ~3×. If leadership must see numbers mid-run, show guardrails — never the primary.

Pre-launch checklist

Gate for step 4. Two of six done — the ramp does not start until required items are checked.
✓ Hypothesis doc reviewed and pre-registered REQUIRED
✓ Sample size and end date computed and calendared REQUIRED
Exposure + assignment events verified on staging REQUIRED
Guardrail metrics wired to daily alert REQUIRED
Screenshot archive of both arms OPTIONAL
Stakeholder note with planned end date OPTIONAL
