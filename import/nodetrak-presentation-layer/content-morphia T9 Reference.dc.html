Naming rules

object_action, snake_case. Lowercase object, then the verb. One event per meaningful outcome, not per button.
checkout_completedexperiment_exposure
Verbs state what happened. _started, _completed, _evaluated, never UI phrasing like _clicked or _tapped. Surfaces change; outcomes don't.
No PII, team names, or surfaces in the name. Surface lives in properties.surface; the owner lives in the catalog. Names outlive both.
Breaking change = new event. Append _v2, mark the old event DEPRECATED, emit both for 90 days. Never mutate a published schema.
checkout_completed_v2
