def compute_shapley(conversions: pd.DataFrame) -> pd.DataFrame:
    model = LinearRegression()
    X = conversions[["paid_search", "display", "email", "organic"]]
    y = conversions["revenue"]
    model.fit(X, y)
    return pd.DataFrame({"channel": X.columns, "contribution": model.coef_})

Summary

The modern measurement stack is not a single model — it's a layered system. Media mix models inform budget allocation, incrementality tests validate channel effectiveness, and attribution models guide daily creative and audience decisions. No single method is sufficient on its own.

Incrementality

The causal lift in conversions attributable solely to advertising exposure, isolated from organic behavior via controlled holdout experiments. It is the only attribution method that accounts for selection bias and establishes true cause-and-effect between spend and revenue.

Key Insight

Shapley values distribute credit fairly by computing the marginal contribution of each channel across all possible channel orderings — not just the first or last touch.

Attribution modeling has evolved significantly since the era of last-touch dominance in the early 2010s. Today, the Shapley value framework is considered the most theoretically rigorous approach for multi-touch environments. Experimental results in Q3 2024 showed an +18.4% improvement in ROAS after reallocation based on Shapley weights — a finding confirmed by geo-holdout tests across three markets. The legacy pixel-based tracking infrastructure that underpins most last-touch setups introduces significant selection bias, particularly on iOS devices post-ATT.

In practice, incrementality testing should always serve as the calibration anchor before deploying any attribution model. Budget decisions driven by uncalibrated models risk directing spend toward channels like branded search (historically credited at 78%) while systematically undervaluing the awareness channels that drive intent in the first place. Campaigns identified as deprecated or non-incremental should be sunset before reallocating budget.

Context

Cookieless measurement requires layering multiple methods. No single model gives the full picture.

The modern stack combines MMM for budget allocation, incrementality tests for channel validation, and multi-touch attribution for daily optimization. Each operates at a different time granularity and data resolution.

2-column — symmetric comparison

Last-TouchAttributes 100% of credit to the final channel before conversion. Simple, zero data requirements. Severely undercredits upper-funnel channels.
Shapley ValueDistributes credit based on marginal contribution across all channel combinations. Handles interaction effects correctly but requires session-level path data.

2×2 text grid — concept matrix

StrengthsHandles cross-channel interaction effects. Accounts for order and recency of touchpoints. Produces channel-level scores for budget reallocation.
WeaknessesComputationally expensive at scale. Requires complete session-level path data. Unstable with small sample sizes per channel combination.
Data RequirementsSession-level event stream with channel, timestamp, and conversion value. Minimum 90 days history. At least 5,000 converting paths per channel cluster.
CalibrationValidate Shapley outputs against geo-holdout benchmarks quarterly. Flag channels where weight deviates more than 20% from measured holdout lift.

3-column — parallel categories

Budget PlanningMMM operates at aggregate channel level, weekly or monthly. Ideal for allocating spend across channels and quarters.
Channel ValidationIncrementality tests measure true causal lift. Use to validate MMM outputs. Run at minimum quarterly per major channel.
Daily OptimizationMulti-touch attribution guides creative and audience decisions at session level. Calibrate against holdout benchmarks monthly.

Case Example Shapley Attribution for a D2C E-Commerce Brand

A direct-to-consumer apparel brand was running six paid channels — Google Search, Meta, YouTube, Pinterest, Display, and Email — with last-touch attribution crediting 78% of conversions to Google Search. The team suspected this was overstating search's contribution.

After implementing a Shapley value model over 90 days of session-level path data, Google Search's share dropped to 41%, while Meta moved from 6% to 22% and YouTube from 2% to 14%. Incrementality holdouts confirmed the reallocation: budget shifted 30% toward Meta and YouTube drove a net +9.2% ROAS improvement within 60 days.

Key takeaway: Last-touch consistently undervalues awareness channels that influence the path but rarely capture the final click.

Steps & Guides

Sequential process steps with connected number markers. Visually distinct from ordered lists — designed for tutorials, setup guides, and methodologies.

01
Define the Measurement Objective

Agree on the north star metric before writing a single line of tracking code. Common options: incremental conversions, incremental revenue, or iROAS. Document the objective and get stakeholder sign-off.

02
Audit the Event Taxonomy

Map every existing tracking event against the data model. Identify gaps in touchpoint coverage — particularly missing upper-funnel events like ad views and landing page visits.

03
Instrument Server-Side Events

For high-confidence conversion data, implement server-side event collection. Browser-based pixels are increasingly unreliable due to ITP, ad blockers, and iOS restrictions.

04
Run a Baseline Holdout Experiment

Before deploying any attribution model, establish incrementality benchmarks per channel via geo-holdout or ghost-ad experiments. This becomes your ground truth for calibration.

05
Model, Calibrate, Iterate

Deploy the attribution model. Calibrate channel weights against holdout results. Set a quarterly recalibration schedule. Flag any channel where model weight deviates more than 20% from measured lift.

Shapley Value — Mathematical Foundation Monte Carlo, game theory...

The Shapley value originates from cooperative game theory. For a set of n players (channels), the Shapley value assigns each player a contribution equal to their average marginal contribution across all possible orderings.

For channel i, the Shapley value φᵢ is computed as the weighted average of the marginal contribution of i when added to every possible subset S of the remaining channels.

# Approximate Shapley via Monte Carlo sampling
def shapley_mc(channels, conversion_fn, n_permutations=500):
    contributions = {ch: 0 for ch in channels}
    for _ in range(n_permutations):
        perm = random.shuffle(channels.copy())
        for i, ch in enumerate(perm):
            subset_with = set(perm[:i+1])
            subset_without = set(perm[:i])
            contributions[ch] += conversion_fn(subset_with) - conversion_fn(subset_without)
    return {ch: v / n_permutations for ch, v in contributions.items()}
